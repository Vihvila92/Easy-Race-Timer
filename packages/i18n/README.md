# @ert/i18n

Finnish and English catalogs, and date and time formatting.

Public entry: `@ert/i18n` (`src/index.ts`) exports `translate`, `parseLocale`, `formatDate`, `formatTime`, `formatDateTime`, and the `fi` and `en` catalogs.

From the repository root: `pnpm exec vitest run packages/i18n`. Setup is in [CONTRIBUTING.md](../../CONTRIBUTING.md).
