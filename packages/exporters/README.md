# @ert/exporters

CSV results and A4 print HTML.

Public entry: `@ert/exporters` (`src/index.ts`) exports `exportResultsCsv` and `exportPrintHtml`.

From the repository root: `pnpm --filter @ert/exporters typecheck`. This package has no test file of its own. `pnpm test` runs the suite. Setup is in [CONTRIBUTING.md](../../CONTRIBUTING.md).
