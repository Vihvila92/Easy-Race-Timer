# @ert/sports

Running profile and the kids-and-adults category template.

Public entry: `@ert/sports` (`src/index.ts`) exports `runProfile`, `sportRegistry` and `kidsAndAdultsTemplate`.

From the repository root: `pnpm --filter @ert/sports typecheck`. This package has no test file of its own. `pnpm test` runs the suite. Setup is in [CONTRIBUTING.md](../../CONTRIBUTING.md).
