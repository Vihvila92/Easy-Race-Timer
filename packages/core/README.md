# @ert/core

Results, categories, errors, times and ids. No I/O.

Public entry: `@ert/core` (`src/index.ts`) re-exports `errors`, `time`, `ids`, `hlc`, `csv`, `category`, `results`, `registry` and `bus`.

From the repository root: `pnpm exec vitest run packages/core`. Setup is in [CONTRIBUTING.md](../../CONTRIBUTING.md).
