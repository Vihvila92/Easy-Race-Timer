# @ert/race-formats

Mass start, including a per-entry offset.

Public entry: `@ert/race-formats` (`src/index.ts`) exports `massStart` and `formatRegistry`.

From the repository root: `pnpm --filter @ert/race-formats typecheck`. This package has no test file of its own. `pnpm test` runs the suite. Setup is in [CONTRIBUTING.md](../../CONTRIBUTING.md).
